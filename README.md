# Stroke Risk Prediction App

A machine learning web application that predicts the risk of stroke based on patient health data using a Random Forest classifier.

## Overview

This project demonstrates an end-to-end machine learning workflow, including data preprocessing, feature preparation, model training, and deployment through Streamlit.

## Features

- Predict stroke risk from patient health information
- Data preprocessing and feature preparation
- Random Forest classification
- Interactive Streamlit web interface
- Trained model and preprocessing artifacts included
- Deployed on Streamlit Cloud

## Tech Stack

- Python
- Pandas
- NumPy
- Scikit-learn
- Random Forest
- Streamlit
- Jupyter Notebook
